# Correlaciones de Features — Período Dev

> Este archivo es un marcador de posición.
> Ejecuta `btcx report features --asset <ID>` para generar el reporte real.

## Contenido generado

El comando CLI genera:
- Matriz de correlación de features en el período dev
- Heatmap de correlaciones
- Estadísticas de cobertura (% de filas válidas por feature)
